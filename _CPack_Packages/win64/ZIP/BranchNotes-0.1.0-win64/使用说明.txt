枝記 Notes 使用說明

啟動
解壓縮後，雙擊 BranchNotes.exe 即可使用。程式適用於 Windows 10 或更新版本，無需另外安裝 Qt 或 Visual C++ 執行階段。

筆記
選擇或建立分類，再建立筆記。正文會自動儲存。工具列可設定標題、粗體、斜體、清單與表格。

心智圖
在筆記內切換到「心智圖」頁面以建立節點。拖曳節點可移動位置；雙擊節點可編輯文字。按住 Ctrl 並點選另一節點可建立連線。可用捲軸或滑鼠滾輪移動畫布。

匯入與匯出
匯入的 TXT、Markdown 或 RTF 檔案會複製到目前選取的分類。可將選取的筆記匯出為 RTF、TXT 或 Markdown。

資料位置與備份
筆記和心智圖資料儲存在：
%LOCALAPPDATA%\BranchNotes\Notes

要備份資料，請先關閉程式，再複製上述資料夾。刪除筆記時，檔案會移至 Windows 資源回收筒。
